게시 연결

goya-jin 계정 확인이 필요합니다. GitHub 웹사이트 로그인과는 별도로 연결해야 합니다.

처음 연결하는 방법
  1. GitHub에서 연결키 만들기를 엽니다.
  2. Repository access에서 Only select repositories → portfolio를 선택합니다.
  3. Permissions에서 Contents: Read and write를 확인하고 키를 생성합니다.
  4. 생성된 키를 위 입력란에 붙여넣고 연결하세요. 채팅으로 보내지 마세요.

키는 이 페이지가 열린 동안에만 사용하며 저장하지 않습니다. 새로고침하거나 다시 방문하면 다시 연결해야 합니다. 만료된 키는 GitHub에서 새로 만들어 주세요.
