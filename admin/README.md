# 사이트에서 글 쓰기

주소: https://goya-jin.github.io/portfolio/admin/
글 페이지 맨 아래의 **글쓰기** 링크로도 들어갑니다.

## 작성

제목과 내용을 작성하고 이미지·첨부파일을 추가하세요.
파일을 본문 중간에 놓으려면 원하는 곳에 커서를 두고 **본문에 삽입**을 누릅니다.
삽입하지 않은 파일은 글 맨 아래에 들어갑니다.
**미리보기**로 본문과 이미지 배치를 확인합니다. 세부 Markdown 서식은 게시 후 적용됩니다.

## 초안

**초안 저장**과 자동 저장은 브라우저의 IndexedDB만 사용합니다.
제목·내용·날짜·파일을 저장하고 새로고침 후 복원합니다.
다른 기기로는 동기화되지 않고, 브라우저 데이터를 지우면 사라집니다.
초안은 GitHub에 전송하지 않습니다.

## 첫 연결

글쓰기 화면의 “처음 연결하는 방법”을 열고 GitHub에서 fine-grained personal access token을 만듭니다.
Resource owner: goya-jin / Only select repositories: portfolio / Contents: Read and write.
사용자가 직접 키를 생성하여 글쓰기 화면에 입력합니다. 키를 채팅이나 저장소에 올리지 마세요.
키는 페이지 메모리에만 유지되며 새로고침/탭 종료 후 다시 입력해야 합니다.
이 화면은 GitHub OAuth 로그인이 아니라 연결키로 GitHub API에 직접 인증하는 방식입니다.
관리 화면의 주소는 공개되어 있지만, 게시 기능은 goya-jin 계정과 저장소 쓰기 권한을 검사합니다.

## 게시 및 수정

**게시하기 → 공개 게시**를 누르면 글과 파일이 하나의 커밋으로 main에 반영됩니다.
자동 배포 완료까지 보통 1–2분이 걸립니다. 게시 버튼은 연결 전에는 비활성화됩니다.
연결 후 “게시한 글 수정”에서 글을 불러와 수정할 수 있습니다.
동시에 다른 곳에서 같은 글이나 저장소가 변경되면 덮어쓰지 않고 게시를 중단합니다.

## 제한

파일당 10MB / 전체 25MB / 최대 8개.
지원 파일: JPG, JPEG, PNG, WebP, GIF, AVIF, PDF, TXT, MD, DOCX, XLSX, PPTX, ZIP, MP3, MP4, MOV.
게시하는 파일과 본문은 공개 저장소와 사이트에 공개됩니다.
